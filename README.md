# Titanic Survival Classification

## Project Description
A machine learning project predicting survival of Titanic passengers based on features like age, gender, class, and fare. Built using Python, Pandas, NumPy, and scikit-learn.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

## Project Steps / Features
- Data cleaning & preprocessing
- Exploratory data analysis (EDA)
- Feature engineering
- Model selection & evaluation (Logistic Regression, Random Forest, etc.)
- Accuracy and performance metrics

## How to Run
1. Clone the repository
2. Install required packages: `pip install -r requirements.txt`
3. Run `titanic_classification.ipynb`
